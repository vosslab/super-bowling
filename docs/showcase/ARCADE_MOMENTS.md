# Arcade moments

Super Bowling changes its visual emphasis with the scale and meaning of the shot. The 105-pin
frames keep individual reactions large, while the ten-pin result states reserve concentrated
color and typography for earned bowling outcomes. The record and handoff frames show how the
game returns from impact to useful player information.

The one-play 105-pin animation records the normal-motion browser build: release, first contact,
and a spreading physical cascade. Its static first-impact and cascade frames directly below give
the same readable outcome when animation is unavailable or lower motion is preferred.

Strike and spare share one compact location but retain distinct amber and cyan identities. The
BEST FRAME message remains above the physical outcome, and the local-player dialog makes the next
person and next action explicit without changing the bowling controls.
