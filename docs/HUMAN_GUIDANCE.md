# Autonomous completion policy

Use this policy when a plan has an implementation or acceptance milestone.

- The manager and subagents must be able to close every milestone unattended. A plan names its
  captured fixtures, synthetic transitions, debug harnesses, automated behavior or probe gates,
  exact commands, and independent-subagent review.
- Perceptual or interaction claims become executable evidence: capture the production scenario,
  exercise a deterministic synthetic transition, measure the stated relation, and retain a
  readable report. A missing speaker, display, or awake person must not block the path to done.
- Independent review means a fresh subagent reads the implementation and the generated evidence,
  then records its disposition. A failed command or review returns work to a bounded package.
- Player feedback is valuable product input. It starts a new request or revises a fixture, but does
  not become a direct-perception or availability requirement for an existing milestone.
- Keep the autonomous-policy verifier's explicit current-doc inputs and automatic active-plan
  discovery current. A newly authored, untracked active plan is subject to the same unattended
  completion rule before it is staged or reviewed.

Human authority remains required for commits,
credential use, releases, destructive operations, or external-state changes that need consent.
