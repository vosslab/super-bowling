# Super Bowling cookbook

Use these short match recipes when choosing a game style for a local session. They build on the
rules in [GAME_RULES.md](GAME_RULES.md) and keep the game's four technique controls meaningful.

## Start a quick solo game

Choose this recipe to learn the lane before inviting other players.

- Select the 10 mode and one player.
- Keep the default two bowls per frame for familiar strike and spare scoring.
- Start with the preview centered, then change one control at a time before each roll.
- Use the visible roll result to decide whether position, angle, power, or spin is the next
  adjustment.
- Finish the match to establish a personal record for the selected rack and bowls-per-frame mode.

## Host a keyboard match

Use one browser and keyboard for a short local game with friends.

- Add two to four players in setup and give each a name and distinct ball design.
- Choose 10 or 20 mode when each player should have a readable, familiar-sized rack.
- Start the match, then follow the `Pass the keyboard` panel after each player completes a frame.
- Let the next player adjust their own four pre-roll controls before pressing Space.
- Use `Play again` at the final score to repeat the same match setup, or choose `Change setup` to
  change players, rack size, or scoring mode.

## Practice a giant rack

Use a larger mode to make the lane a technique problem rather than a standard bowling recreation.

- Choose 100, 500, or 1,000 mode; the setup displays the actual complete-triangle pin total.
- Begin in Classic two-bowl scoring if the group wants strikes and spares to remain meaningful.
- Increase the displayed power only after checking the pins-free preview path.
- Use start position, angle, and spin together to create an entry path instead of relying on a
  centered launch.
- Treat the 1,000-label mode as its intentionally fantastical 990-pin challenge; its power and
  spin limits are larger than the ten-pin envelope.

## Run a bonus-free pinfall drill

Use Super frame scoring to focus on one shot shape or cascade without Classic strike and spare
bonuses.

- Select three through five bowls per frame in setup.
- Choose a rack size that makes the target pattern easy to see at the available screen size.
- Repeat a planned adjustment across several bowls and compare the displayed pinfall.
- Remember that Super frame scoring uses actual pinfall and numeric marks, not strike or spare
  bonuses.
- Compare practice records only within the same rack size and bowls-per-frame setting.

## Set up a quieter session

Use the preferences when a player needs less sensory activity without losing game information.

- Toggle `Mute` in setup or during a match to control synthesized sound.
- Toggle `Reduced motion` in setup or during a match when a player wants the saved lower-motion
  presentation; [ACCESSIBILITY.md](ACCESSIBILITY.md) defines what it preserves.
- Use the keyboard controls or the visible range controls; both operate the same launch values.
- The browser remembers mute, reduced-motion, recent setup, and practice records for later local
  sessions when browser storage is available.
